# 本地音色管理工具

本工具是 Memo 多后端 TTS 插件的可选本机辅助程序，用来准备自有讲师音色、查看已有音色并维护临时/持久生命周期。它不参与插件合成链路，也不是插件运行依赖。

本工具提供本机 HTTP 服务、中文页面与显式启动入口。已有音色只读导入、管理页桌面/窄屏交互，以及 TTS 插件的真实 Audio8 合成和 Memo 原生导入有阶段性实测；新讲师音色的真实注册、完整生命周期及“视频采样→新音色→译文配音”仍未验收。不要把工具存在理解为采集闭环已经可用。最新范围见 [项目状态说明](PROJECT_STATUS.md)。

## 准备隔离资料根

工具只接受显式给出的资料根，不会默认使用用户目录。首次使用先建一个空目录：

    mkdir -p ~/memo-tts-root

显式初始化（只在 --initialize 时创建）：

    node manager/index.js --root ~/memo-tts-root --initialize

初始化会在该目录下创建 owner.json、catalog.json 以及 sources、voices、derived、operations 四个子目录。普通启动不会创建或补齐任何内容，缺 catalog.json 会直接失败。

## 启动与停止

    node manager/index.js --root ~/memo-tts-root

也可以指定端口（默认 0 表示自动分配），或使用 npm 脚本：

    node manager/index.js --root ~/memo-tts-root --port 0
    npm run manager -- --root ~/memo-tts-root

启动后终端会打印本机访问地址（形如 http://127.0.0.1:端口）。服务只监听 127.0.0.1，会话令牌只存在内存中，不写 URL、日志或浏览器存储。

停止：在终端按 Ctrl+C。停止只关闭本工具自己的 HTTP 服务，不会停止 Audio8/GPT-SoVITS 模型进程，也不会删除资料目录、归属记录或锁文件。

## 与插件的关系

- 插件的合成链路只读 catalog.json 与自有资料目录，不依赖本工具是否运行。
- 本工具是唯一写入自有资料目录的组件；插件不会反向写入目录。
- 资料根与 Audio8 安装目录严格分离：本工具只向自有资料根下的 voices/ 注册新音色。

## 使用前必须明确的现状

- 端点需要人工配置：本批不提供新增或修改端点的 HTTP 接口，页面只显示 catalog.json 里已经登记的端点。没有端点时请在资料目录中显式配置后再使用。
- 目录声明就绪不等于真实可用：页面显示的是 catalog 声明的状态，不代表已经在线校验过声音，也不代表试听过。
- GPT-SoVITS 保持未验证且不可用：本批不对 GPT 端点做导入或准备，只支持已验收的 Audio8 路径。
- 授权责任在使用者：准备音色前必须确认已取得该声音的使用授权。工具只记录你的确认，不代为判断版权或授权范围。
- Audio8 注册门禁：注册只走 Audio8 自身的 /api/voices/register，且要求在线 runtime 的 voicesRoot 与本资料根的 voices/ 完全一致；不会向既有安装目录写标记或认领旧声音。

## 失败与双状态

准备音色会同时产生两件独立的结果：

- 注册阶段（registrationState）：pending / registered / unknown / failed。一旦请求已经发出，工具不会自动重发。
- 目录提交（commitState）：notCommitted / committed。目录未提交不等于注册没有发生。

因此失败提示分多种情况：

- unknown：注册请求没有确认完成（超时或断连）。录音与归属记录会保留，需要人工核对，不要直接重复提交。
- failed：服务明确拒绝（如参数非法或同名冲突），原目录不变，可以修正后重新准备。
- committed 但记录末步失败：音色实际上已经注册，绑定已落盘。这类错误必须人工核对后再决定，不能当成未创建。

失败后 source 记录与 operation 记录会保留，用于人工排查；工具不自动回滚、不自动清理、不自动重试。

## 遗留状态的处理

崩溃或失败可能留下锁文件、临时文件或未完成记录。工具不会自动认领或删除这些文件。请人工确认目录内容后再处理，必要时保留现场交给维护者。

## 未验收范围

以下内容尚未真实验证，不能据本文档推断为已通过：

- 真实 Audio8 注册耗时、真实讲师录音与真实授权语义。
- 完整键盘无障碍与所有错误分支；已有桌面/窄屏和只读导入实测不代表全面覆盖。
- 新采集 App 的原生采样、注册、译文合成与人工听感闭环；TTS 基础包的原生导入和播放控件证据不能替代它。
- GPT-SoVITS 的端到端可用性。

## 安全边界摘要

- 只监听 127.0.0.1，Host 必须精确匹配本实例地址，出现转发头即拒绝。
- 写请求要求有效会话 cookie、CSRF 头与精确同源 Origin；不提供任何 CORS 头，OPTIONS 预检被拒绝。
- 页面上传只接受浏览器选择的文件，先校验大小再分块编码；不接受任意路径、URL 或代码输入。
- 静态资源只按固定映射提供三个文件，不存在任意文件读取；响应带 CSP 与 nosniff。
