# 项目交付状态

更新日期：2026-10-16。本文是本次 GitHub 源码归档的当前状态说明；早期设计稿、执行清单和阶段报告不能替代本文的现状结论。

## 一句话结论

这是“Audio8 已有音色 TTS 基础已实现并有部分实机证据，视频音色采集仍处于未完成验真的实验原型”状态的开发快照，不是完整交付、正式发布或双后端均可用的版本。

目标功能是：在 Memo 中打开视频，采集原讲者音色，再用该音色朗读译文。这个目标目前没有实现并通过端到端验收。尚未证实可行，也没有通过关键接口失败证据证明不可行；不能把候选架构或静态接口调查当成已可用产品。

当前已观察到的阻塞是测试文稿创建：Memo 首页“选择本地媒体”接受自有 MP4 后进入转写设置；取消转写会放弃导入。没有在该流程找到只导入或跳过转写的入口。本地 Whisper Tiny 模型文件和随附运行时已在位，但未实际执行转写，不能声称离线运行已验证。原文/译文轨建立、App 接口返回和后续模型步骤因此尚未测到。

这个阻塞不是“宿主插件接口已证实不支持”。静态代码已经找到文稿数据、媒体字段和应用桥的调用路径，但字段存在与实际权限、可读性和传输成功是不同层次的证据。

当前测试在 macOS ARM64、Node.js 22 的本机环境运行；部分 Python 辅助测试依赖已有 uv 与本地 Audio8 虚拟环境，缺失时会条件跳过。部分测试夹具仍带开发机器的示例路径，完整跨机器可移植性尚未收口。

## 已知缺口与风险

- 尚无“当前视频→自动采样→新音色→译文配音”的可用闭环，实验 App 不应按完整功能推荐安装使用。
- 初次验证器审查曾发现授权前解码、状态不准确、手写证据可误签通过、没有真正进行译文合成/播放/保存等问题；0.1.1 已做整改，但未形成最终原生验收结论，也不宣称所有审计线索均已关闭。
- 运行关联字段、challenge/日志失败记录、保存后读回校验及音频大小边界仍需结合最终实现与实机结果核查。摘要、nonce 或本地文件不能单独证明 Memo 真正执行过；用户试听也不能由播放按钮状态代替。
- 新真实讲师音色注册、临时转持久与结束的实机流程未通过；准备声音前须取得相应使用授权，不能由工具代替用户确认。
- GPT-SoVITS 未完成可靠模型身份核验，不因协议测试通过而启用。
- 真实换录音、换模型、换端点后的缓存行为及历史缓存处理未验收；原生历史音频不会被管理工具自动改写或删除。
- 峰值 RSS 未测；不以当前 RSS 或音频振幅冒充内存峰值。
- Memo 本体锁定，不允许修改、解锁或运行时注入。后续若现有插件接口不足，应明确记录该路线失败，不把修改宿主当默认退路。
